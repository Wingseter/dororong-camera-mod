# Phase 0: 해상도 진실 검증 — 완료

> 일시: 2026-03-29
> 결과: 센서 native 해상도 = 1280x720 (1MP) 확정

## 확정된 사실

| 항목 | 결과 | 근거 |
|------|------|------|
| 센서 native 해상도 | **1280x720** | UVC 단일 해상도 (Windows/Mac 양쪽 확인) |
| UVC 웹캠 모드 | 1280x720 only | Windows 카메라 앱: 해상도 선택지 720p만 표시 |
| 카메라 독립 영상 | 1280x720 @ 30fps | SD 카드 AVI 파일 (MOVI*.avi) |
| 카메라 독립 사진 | 1600x1200 (2M 설정) | SD 카드 JPEG, bpp=0.095 (업스케일 수준) |
| ISP 하드웨어 상한 | 720p | GPCV2247F 공식 사양: "ISP supports raw data sensor up to 720p" |
| 1080P/12M/8M 모드 | **업스케일 (가짜 해상도)** | 센서 720p → ISP 스케일러로 확대 |

## 검증 데이터

### 웹캠 캡처 (Windows)

```
파일: WIN_20260329_02_05_38_Pro.jpg
해상도: 1280x720
크기: 103,275 bytes (bpp = 0.112)
Laplacian variance: 28.2
Gradient mean: 2.77
밝기: 평균 80.3, 범위 9~255
```

Windows 카메라 앱에서 선택 가능한 해상도: **720p만 표시** (다른 옵션 없음)

### SD 카드 사진 분석 (기존 32장)

```
전체 32장: 1600x1200 (2M 모드)
평균 bpp: 0.095 → 업스케일 가능성 높음
Q-table 평균: 28.9 (전 사진 동일)
```

### SD 카드 영상 분석 (기존 2개)

```
MOVI0007.avi: 1280x720, 30fps, GPEncoder
MOVI0015.avi: 1280x720, 30fps, GPEncoder
```

### 펌웨어 분석

- UVC Frame Descriptor: 640x480으로 광고 (실제 출력은 720p — 런타임 설정)
- 1920x1080 / 1280x720 프레임 버퍼 상수: 펌웨어 바이너리에 없음
- 메뉴 문자열에 1080P/720P/VGA/12M/8M/2M/1M 존재 (ISP 스케일러 경유)

## 결론

```
★ 센서 native = 1280x720 (약 1MP)
★ 1080P 영상 = 720p 업스케일
★ 12M/8M/2M/1M 사진 = 720p 업스케일
★ 모든 화질 튜닝은 1280x720 기준으로 진행
★ 업스케일 모드는 화질 개선 대상에서 제외
```

## 프로젝트에 미치는 영향

1. **튜닝 기준 해상도**: 1280x720 고정
2. **사진 모드**: "VGA" 또는 "1M"이 오히려 깨끗할 수 있음 (업스케일 없이)
3. **영상 모드**: "720P"가 native → 이것만 최적화
4. **JPEG Q-table**: 720p 프레임 기준으로 최적화
5. **Phase 6 프리셋**: 720p 기준으로만 설계
