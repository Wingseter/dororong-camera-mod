# SD 카드 업그레이드 성공 기록

> 일시: 2026-03-29
> 결과: 커스텀 펌웨어 SD 업그레이드 2회 연속 성공

## 성공한 파일명 규칙

```
JH_5307_[빌드문자열 13자][체크섬 8자 hex].bin
```

### 규칙 상세

| 필드 | 길이 | 설명 |
|------|------|------|
| `JH_5307_` | 9자 | 고정 접두어 |
| 빌드 문자열 | 13자 | 현재 빌드 `"2025004291200"`과 앞 12자가 달라야 함 |
| 체크섬 | 8자 | 파일 전체 바이트합의 32비트 대문자 hex |
| `.bin` | 4자 | 확장자 |

### 체크섬 계산

```python
file_sum = sum(firmware_bytes) & 0xFFFFFFFF
checksum_str = f"{file_sum:08X}"
```

## 이전 실패 원인 (해결됨)

`JH_5307.bin` (체크섬 없는 파일명)으로 시도 시 "Program error please check file" 발생.

**원인**: 업그레이드 함수(FUN_00041678)가 파일명의 22번째~29번째 글자를 hex 파싱하여 기대 체크섬으로 사용. 짧은 파일명에서는 해당 위치가 널/쓰레기 → hex parser가 0 반환 → 바이트합과 불일치.

### 메커니즘 상세

```
findfile 결과 구조체 (R4 = 0x0007DC18):
  +14 (0x0E): 파일명 시작
  +22 (0x16): fname[8] → 빌드 문자열 비교 (12바이트, memcmp)
  +35 (0x23): fname[21] → 체크섬 hex 파싱 (8바이트, strtoul)

파일명: JH_5307_AAAAAAAAAAAAAXXXXXXXX.bin
         ^^^^^^^^                          고정 접두어 (8자)
                 ^^^^^^^^^^^^^             빌드 문자열 (13자)
                              ^^^^^^^^     체크섬 hex (8자)
```

## 핵심 교훈

1. **와일드카드 `*`는 체크섬 인코딩 자리** — `JH_5307*.bin`의 `*`에 빌드+체크섬이 들어감
2. **체크섬은 단순 바이트합** — 파일 전체 바이트를 32비트로 합산
3. **CH341A 불필요** — SD 카드만으로 펌웨어 수정 가능
4. **부트로더 XOR 체크섬과 무관** — SD 업그레이드는 자체 바이트합 검증만 수행
