# Ghidra 심층 분석 결과

> 일시: 2026-03-28

## 1. Brightness 기본값 [확정]

### 위치: 0x08279E

```
0x08279C: 10 00  ← 현재 밝기 값 (또 다른 참조?)
0x08279E: 10 00  ← ★ UVC Brightness DEFAULT = 16
0x0827A0: 01 00  ← Resolution = 1
0x0827A2: FF 00  ← MAX = 255
0x0827A4: 01 00  ← MIN = 1 (또는 추가 Resolution)
```

### 수정 방법

| 오프셋 | 현재 | 변경 | 효과 |
|--------|------|------|------|
| **0x08279E** | `0x10` (16) | `0x80` (128) | 웹캠 기본 밝기 128 |
| 0x08279C | `0x10` (16) | `0x80` (128) | 추가 밝기 참조값 (같이 변경 권장) |

**이것이 Windows에서 밝기가 16/255로 극히 낮았던 근본 원인!**

## 2. UVC 파라미터 테이블 전체 맵 (0x082790 영역)

```
0x082790: 00 01 ff ff ff 03 08 01 23 00 a0 01 10 00 10 00
0x0827A0: 01 00 ff 00 01 00 1f 00 01 01 15 16 05 00 00 00
0x0827B0: 00 00 00 00 00 00 ff 00 00 60 09 00 00 02 00 00
```

해석:
- 0x0827AA: `15 16 05 00` = 333,333 (100ns) = 30fps 프레임 인터벌
- 0x0827B6: `FF 00` = 255 → max packet 관련?
- 0x0827B8: `00 60 09 00` = 614,400 = 1280×720÷1.5 → 프레임 버퍼 크기

## 3. 설정 블록 (0xC2000~0xC5000) 구조 [확인]

### 블록 레이아웃

14개 유효 블록 발견. 각 블록 512바이트 (0x200).

```
+0x00: [모드] [영상해상도] [사진해상도] [플래그]
+0x04: [00] [08] [00 00 00 00 00 00 00 00 00]
+0x0F: [02] [WB] [노출] [밝기?] [01]
+0x17: [01] [01] ...
+0x29: [03] ...
+0x38: [01] [04] ...
+0x3F: [플래그] (0x00 또는 0x01 변동)
+0x95: [플래그] (0x00 또는 0x01 변동)
+0xA0: [01] [00 00 00] [체크섬 4B] [00...]
```

### 블록 간 차이

| 오프셋 | 값들 | 추정 의미 |
|--------|------|----------|
| +0x03 | 0x00 / 0x01 | 모드 변형 플래그 |
| +0x3F | 0x00 / 0x01 | 설정 활성화 플래그 |
| +0x95 | 0x00 / 0x01 | 추가 플래그 |
| +0xA4~A7 | 블록마다 다름 | **블록 체크섬** (CRC 또는 해시) |

체크섬 값 패턴: `53 3d d3 45`, `10 8b 3a e5`, `84 96 e3 72`, `c7 20 0a d2`

## 4. GPZP 리소스 포맷 [부분 확인]

### 파일 테이블 (0x084200)

헤더: `GP 10 00 01 00 01 00` → "GP" 매직 + 파일 수 16개

파일 테이블 구조가 24바이트 단위이나 정확한 파싱은 추가 작업 필요.

### GPZP 데이터 (0x085600+)

GPZP 매직 뒤에 바로 압축/인코딩된 이미지 데이터가 따라옴.
고엔트로피(7.9)로 압축된 상태. 포맷 해독은 Generalplus SDK 리버스 엔지니어링 필요.

## 5. 내장 WAV 리소스 [확인]

| 오프셋 | 크기 | 포맷 | 추정 파일 |
|--------|------|------|----------|
| 0x085800 | 4KB | 11025Hz 16bit mono | BEEP.WAV |
| 0x086800 | 5KB | 11025Hz 8bit mono | CLICK.WAV |
| 0x087E00 | 7KB | 32000Hz 16bit mono | CAMERA.WAV (셔터음) |
| 0x0AAA00 | 17KB | 11025Hz 16bit mono | POWERON_AUDIO.WAV |
| 0x0AF000 | 17KB | 11025Hz 16bit mono | POWEROFF_AUDIO.WAV |

WAV 파일은 표준 RIFF WAV 포맷이므로 교체 가능 (같은 크기 이하).
